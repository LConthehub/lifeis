# Security

## Report a problem

Please do not open a public issue for a security problem.

Report it privately: go to the repository on GitHub, open the **Security** tab, and choose **Report a vulnerability**.
This opens a private security advisory that only the project owner can see.

Include:

- What the problem is and what an attacker could do with it.
- The version or commit you tested.
- Steps to reproduce it, or a small example.
- Whether you have shared it with anyone else.

## Supported versions

Only the latest version gets security fixes. Please update to the latest version before you report a problem.
